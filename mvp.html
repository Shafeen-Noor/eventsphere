EventSphere · MVP

Minimum viable product — live today

EventSphere is a per-event digital experience: one QR code, one hub for photos, guestbook, polls, feed, and host controls. No guest app install required.

Live app

eventsphere-orcin.vercel.app

Demo event

/e/demo — seed with npm run db:seed-demo

Core user flow

  1. Create — host picks event type, name, date (no signup required)
  2. Share — QR code + link from host dashboard
  3. Join — guests enter by name in browser, upload photos, guestbook, reactions
  4. Engage — live feed, polls, challenges, seating, slideshow
  5. Upgrade — Essential ($19) or Premium ($39) when limits are hit
