01 Executive Summary

EventSphere’s MVP is a per-event digital experience, not a generic photo gallery. Each event receives a branded mini-site: invite landing, guest hub, live feed, host dashboard, and QR entry point. The product is deployed on Vercel and usable end-to-end without a mobile app install.

02 Problem & Product Thesis

The fragmentation problem

Event hosts currently stitch together multiple tools: Evite or Eventbrite for invites, WhatsApp for coordination, Google Photos or iCloud for memories. No single product owns the full journey from planning through post-event archive. EventSphere’s thesis is to become that unified layer — starting with the highest-emotion, highest-urgency moment: collecting and reliving guest-contributed media during and after the event.

Why QR + browser beats “download our app”

  • Guest adoption: Wedding and party guests will not install an app for a four-hour event. A QR scan to a mobile web page removes that barrier.
  • Host speed: Create flow requires no account for the first event; host gets a link and QR immediately.
  • Partner distribution: Photographers and planners can say “scan this for tonight’s album” at the venue — natural fit for the partnership channel modeled in unit economics.

03 What the MVP Is (and Is Not)

The MVP IS

  • A live event website per occasion
  • Guest photo/video upload from phone camera
  • Guestbook, reactions, live feed, polls, votes, challenges
  • Host dashboard with QR, moderation, upgrade path
  • Slideshow mode for venue screens
  • Plan-based limits on guests, uploads, retention

The MVP IS NOT (yet)

  • Full invitation & RSVP platform
  • Production Stripe billing (simulated checkout)
  • Production-grade face recognition
  • Real email OTP authentication
  • Printed photo books or physical fulfillment
  • Native iOS/Android apps

04 User Flows

4.1 Host flow

  1. Land on marketing home → click Create Event
  2. Wizard: select event type (wedding, birthday, corporate, etc.) → name → date
  3. Dashboard: receive unique slug URL, QR code, guest count, upgrade prompts
  4. During event: display QR at entrance; optional slideshow on projector
  5. Moderate: approve/remove uploads; pin featured photos
  6. Upgrade: when guest or media limits hit, choose Essential or Premium (simulated payment in MVP)

4.2 Guest flow

  1. Scan QR or open shared link
  2. Enter display name (no account)
  3. Use hub tabs: Gallery · Guestbook · Feed · Polls · etc.
  4. Upload from camera roll or capture in-browser
  5. React to others’ posts; participate in polls/challenges if enabled

4.3 Partner-influenced flow (GTM)

A photographer or planner introduces EventSphere during event setup. The host pays upfront (paid-only GTM in economics model) or upgrades at the guest limit. Partner earns 20% commission on successful sale — see Partnership channel for funnel assumptions.

07 MVP Scope — In vs Out

In scope (demonstrable today)

  • End-to-end create → share → guest join → upload → host view
  • 20+ engagement API routes (guestbook, feed, polls, challenges, seating, audio, etc.)
  • Postgres persistence via Prisma; migrations applied on deploy
  • File storage via AWS S3 or local fallback for development
  • Production deployment on Vercel with environment-based configuration

Out of scope (post-MVP)

  • Real payment processing (Stripe integration)
  • Email/SMS invitation delivery
  • Ticketing and paid admission
  • Native mobile apps
  • Full PRD “before / during / after” feature parity with Eventbrite + GuestPix combined

09 Validation & Next Milestones

What this MVP proves

  • Hosts can launch an event hub in under two minutes
  • Guests participate from mobile browser without friction
  • Engagement features (not just uploads) differentiate from simple gallery apps
  • Unit economics work at $19/$39 with partnership-led acquisition (CAC, LTV)

Recommended next build priorities

  1. Stripe checkout for Essential / Premium (replace simulated upgrade)
  2. Partner referral tracking + commission reporting
  3. Align live pricing display with economics model ($19 / $39)
  4. Interview-backed refresh of funnel conversion rates in CAC model
  5. Invitation landing + RSVP (first “before event” PRD slice)
